# Product Mission

Build a public DeltaXY Company Handbook, with Engineering as its first section.

The handbook should help people:

- Find guidance and understand its purpose.
- Ask questions in the context of the guidance they are reading.
- Propose changes through a rich-text editor.
- See who approved the exact wording that was published.

## Personas

- **Engineers:** Read the handbook to understand company guidance and its purpose, apply it in their work, ask questions in context, and propose changes.
- **Coding agents:** Read the handbook and follow its published guidance when carrying out engineering tasks.

## Experience

Start with a straightforward, read-first website where everyone can see the standards. Readers should not need Markdown or GitHub knowledge to use the handbook.

Confluence-style collaboration remains the longer-term goal. Contextual questions, rich-text proposals, and an application-managed approval workflow are deferred from the initial publishing scope. Maintainers initially edit the handbook through Markdown and Git; existing draft and approval status must remain visible.

## Scope

This is a company handbook, not a general-purpose knowledge-management platform.

See [Project Guidelines](project-guidelines.md) for the initial technology choices, content publishing rules, and deployment plan.
